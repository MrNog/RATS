# Hub cards — art for the hub page's cards (format J)

One image per card on the hub (`index.html`). Format rules live in [STYLE.md → J](../STYLE.md#j--hub-card-1610-no-text).
Save each result as `images/hub/<file>.png` (the name is given per prompt); the page shows it cropped to 16:10.

Each prompt is complete on its own: copy it whole into the generator.
