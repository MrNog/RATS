# Mongoloide — promoção Sewer → Raider Rat (21 Sep 2026)

Pacote pedido pelo próprio: **banner de perfil Prot**, **banner de perfil Ret**, **Discord profile pic**.
Identidade base em [`mongoloide.md`](mongoloide.md) — mesmo rato nas duas specs.

> **Pedido dele, literal:** *"Não sou o maior fã dos dourados a la elden ring"*. A ficha estava travada em
> gold-white; foram-lhe dadas três paletas e ele **escolheu o bronze fosco** — bronze gasto, oxidado e
> mate, nunca ouro polido. Só essa ficou; as variantes frias foram descartadas.

## Como usar

**Copia um bloco inteiro e cola. Não é preciso editar nada.**

- **1B** — banner de perfil, Protection · **entregue** → `images/profile-bg/mongoloide/mongoloide.png`
- **2B** — banner de perfil, Retribution · **entregue** → `images/profile-bg/mongoloide/mongoloide-ret.png`
- **3-ESCOLHIDO** — Discord profile pic · por gerar

Os banners estão entregues; os prompts ficam aqui para regerar ou variar sem perder a identidade. O site
carrega **um** ficheiro por toon (`mongoloide.png`), por isso o Prot é o que aparece no perfil e o Ret fica
como alternativa.

**Onde gravar os banners:** `images/profile-bg/mongoloide/mongoloide.png`. A página de perfil carrega pelo
nome do toon em minúsculas, e o CSS escurece o terço esquerdo para o texto — é por isso que os prompts
pedem esse lado vazio.

## Notas

- **Prot vs Gathlock:** Gathlock é espada + escudo torre a arder em fogo dourado. Mongoloide Prot é
  **martelo 1H + escudo torre**, sem chama. Mantém as duas silhuetas separadas.
- **Ret:** martelo de duas mãos, sempre vertical. Nunca espada — essa é do Rellik.
- **Enquadramento do banner:** não é o "bust virado para o centro com a arma ao ombro" — esse é o do
  Grunho. O Prot é frontal atrás do escudo, o Ret é a três quartos com o martelo no canto superior direito.
- **Paleta travada:** bronze fosco. O "Do NOT include" proíbe o ouro brilhante e a gilding ornamental, mas
  deixa passar o bronze gasto — é essa a diferença que faz o look dele.
