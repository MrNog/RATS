# RatTree — spec rats (talent window art)

The art behind RatTree's talent trees: one rat per **spec** (30). Until a spec has its own image, the window uses the class rat from `images/okanvil/class-rats/`.

## Rules for all 30

- **2:1, 2048x1024, NO text.** No name, title, watermark, logo or insignia.
- **A generic rat, not a raider.** Nobody should mistake it for a guild member's portrait.
- **The rat stands at about 72% across**, head to knees. The **left 60% stays calm and dark**: the talent trees are drawn over it and the window darkens it further.
- The window shows the art in **grey, tinted with the spec's colour**, so strong light and dark shapes matter more than colour.
- Locked style, tone, build and anatomy from [`../STYLE.md`](../STYLE.md). Every spec has its own build, face, pose and scene.

**Saving:** put each PNG in `images/okanvil/spec-rats/<class>-<spec>.png` (the file names are in each heading). Then ask Claude to convert them: each becomes `wow-addons/RatTree/Media/Art/<class>-<spec>.blp` (1024x512 BLP DXT5) and is switched on in RatTree's `RT.SPEC_ART`. WoW needs a full restart.
